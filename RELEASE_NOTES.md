## TIde 1.5.1

- **Updates come from stable releases:** TIde now checks the newest tagged release for updates, never the rolling prerelease that every commit refreshes. If an earlier version showed "could not fetch a valid release JSON from the remote", this update fixes it, and later updates arrive as usual.

Everything new in 1.5.0 is here too: the Output, Terminal and Console panel, shell commands in `.tide/tide.json`, the live Explorer, and IntelliSense from the catalogs for C, assembly and py2ez80.
