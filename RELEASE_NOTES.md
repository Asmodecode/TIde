## TIde 2.0.0

- **TI-Nspire CX:** the calculator panel now runs a TI-Nspire CX, on [Firebird](https://github.com/nspire-emus/firebird)'s core (GPLv3), built into TIde like CEmu and Wabbitemu. It runs from two images dumped from your own calculator, boot1 and flash. Files sent to it stay in its flash image for next time. Its keypad is laid out like the real calculator's, in TIde's colors, with the touchpad and its click in the middle. Nspire support was contributed by grovylestand.
  - **The Nspire extension** adds completions and hover help for Nspire Lua and the Ndless SDK's C and C++ API. Its commands start a Ndless project in the open folder, build it with make, pack `.lua` and `.py` scripts into `.tns` files with Luna, and send them to the panel's Nspire.
- **Calculator images:** one popup now holds every ROM and image the emulators run from, with a tab for each family: the CE calculators, the TI-Nspire CX, and the TI-73 to 86. Each image is a card saying what it is, with buttons to start, replace or remove it. The model menu lists only the calculators you have images for, plus **Add a ROM…**, which opens the popup.
- **Every CE calculator, as many as you like:** CEmu runs the TI-84 Plus CE, the TI-83 Premium CE and the TI-82 Advanced Edition Python. TIde reads which one a ROM is from, and its boot code version, as CEmu does, and names it that way in the menu. Keep several CE ROMs side by side. Two ROMs with the same file name are both kept, the second as "name (2)". Your CE.rom from before moves over by itself.
- **ROMs say what they are:** a ROM for the TI-73 to 86 is listed by the model and OS read from it, such as "TI-84 Plus · OS 2.55MP", before it's ever started.
- **Keypads:**
  - Every key shows what 2nd and alpha make of it, printed above it as on the calculator. While 2nd or alpha waits for the next key, its labels light up.
  - The TI-81, 82, 83, 85 and 86 each get their own keypad, with the labels their guidebooks give (RANGE on the TI-81, MATRX on the 82 and 83, F1 to F5 and EXIT on the 85 and 86).
- **TI-Python:** `.py` files are TI-Python, for the TI-84 Plus CE Python and TI-84 Evo, with TI module completions, hover help, starter programs and module docs in the Docs view. Use TI Connect CE or TI Connect Evo to send them. py2ez80 source files use Monaco's Python language.
- **Setting up a folder:** opening a folder whose `tide.json` doesn't say which calculator it's for, or what it's written in, asks. It shows what the folder's files point to, with **Other calculators…** and **Other languages…** for when they're wrong, and menus for the prerun and postrun steps: shell commands, pressing keys, typing, running a program or app, and waiting. The files it looks at: a Makefile using the CE toolchain or the Ndless SDK, Lua scripts, z80 or eZ80 assembly, C, C++, Python. The answer goes in `tide.json`, as `"calculator"` and the new `"language"`: TI-BASIC, C, C++, eZ80 or z80 assembly, TI-Python, py2ez80 or Lua. A folder without a `tide.json` gets a whole one for its kind: its build, prerun and postrun steps, what Run sends, the CE libraries, where it runs and its scripts. In a py2ez80 project `.py` files open as py2ez80, and in a z80 project its assembly opens as z80. `.py` scripts pack into `.tns` files again in a TI-Nspire project. **Settings → Project** sets when TIde asks (always, only when the files point more than one way, or never), and can set a folder up again.
- **A project's calculator decides:** `tide.json`'s `"calculator"`, now the TI-Nspire CX too, sets TI-BASIC's screen checks and commands and what Build and Run make while the project is open. The status bar's Target button is gone: the setup popup (**Settings → Project → Set up this folder…**) changes a project's calculator, and **Settings → Calculator** sets it outside a project.
- **Images in the editor:** PNG, JPEG, GIF, BMP, WebP, AVIF, ICO and SVG files open as pictures in the editor, on a checkerboard so transparency shows. They open fitted to the editor. Zoom with the − and + buttons, Ctrl+wheel or a pinch, or with the + and − keys; 0 fits the picture again. Past 100%, pixels stay sharp, for sprites.
- **Smaller fixes:**
  - The status bar's Scripts menu stays the same size however long your scripts' commands are.

Everything new in 1.7.0 is here too: one popup for connecting a real calculator, serial cables, and files changed outside TIde reloading in their tabs.
