The web version
===============

TIde runs in the browser, with nothing to install:

- **Stable:** `xsamuraicoder.github.io/TIde <https://xsamuraicoder.github.io/TIde/>`_, which changes
  with each release.
- **Nightly:** `xsamuraicoder.github.io/TIde/nightly <https://xsamuraicoder.github.io/TIde/nightly/>`_,
  from every push to ``main``.

Installing it as an app
-----------------------

Press **Install** at the top right, or use your browser's menu: Chrome and Edge install it, and
Safari adds it to the Dock (on iPhone and iPad, Share → Add to Home Screen). Firefox can't install
sites as apps. An installed TIde opens from your apps, and opens offline too, from the copy it keeps
of the site. The nightly installs as its own app, **TIde Nightly**.

What it has
-----------

The editor, IntelliSense, docs, extensions and all three calculator emulators. It builds TI-BASIC
into ``.8xp`` files, assembles z80 and eZ80 with spasm-ng compiled to WebAssembly, and compiles C in
the browser.

- **File → Open folder…** opens a real folder on your computer in Chrome and Edge.
- **File → Open browser project…** keeps a project in the browser's own storage, on any browser.
- Calculator ROMs stay in the browser's storage too.

What's only in the desktop app
------------------------------

The terminal, source control, the CEmu app, the TI-Nspire's command-line tools (Ndless and Luna),
moving files to the Recycle Bin, and updates. The web version is always the one on its page, so it
has nothing to update.
