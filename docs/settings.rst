Settings
========

**Settings** is the gear at the bottom of the activity bar, or :kbd:`Ctrl+,`. A project's
:doc:`tide-json` can set the editor settings for itself.

.. list-table::
   :header-rows: 1
   :widths: 22 78

   * - Section
     - What it sets
   * - Look
     - Dark, light, or the system's.
   * - Editor
     - Font size, tab size, word wrap, the minimap, whitespace.
   * - TI-BASIC
     - The calculator programs are for, the gutter, the screen-width ruler.
   * - Files
     - The encoding for other text, auto save, Shift for permanent delete.
   * - C projects
     - Sending ``clibs.8xg`` with C projects.
   * - TI-Nspire
     - The Ndless SDK folder and the Luna command. Desktop app only.
   * - Project
     - When to set up a folder as it opens, **Set up this folder…**, and its ``tide.json``.
   * - Source control
     - Refreshing git status when TIde gets focus. Desktop app only.
   * - Updates
     - Checking for updates on start, the update channel (Stable or Nightly), and checking now.
       Desktop app only.
