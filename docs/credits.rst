Credits
=======

Contributors
------------

- `grovylestand <https://github.com/grovylestand>`_: TI-Nspire CX support, with the Firebird
  emulator in the calculator panel and the Nspire extension.

Built into TIde
---------------

- `CEmu <https://github.com/CE-Programming/CEmu>`_ by the CE Programming team: the TI-84 Plus CE,
  TI-83 Premium CE and TI-82 Advanced Edition Python.
- `Wabbitemu <https://github.com/sputt/wabbitemu>`_ by Spencer Putt, Chris Shappell, James Montelongo
  and others, through `wasmWabbitemu <https://github.com/marwatk/wasmwabbitemu>`_ by Marcus Watkins:
  the TI-73, 81, 82, 83, 83 Plus, 84 Plus, 85 and 86.
- `Firebird <https://github.com/nspire-emus/firebird>`_ by the nspire-emus team: the TI-Nspire CX.
- `TILP's libraries <https://github.com/debrouxl/tilibs>`_ by Romain Liévin, Lionel Debroux and
  others, built for the web as WebTILP by `Adrien Bertrand <https://github.com/adriweb/tilibs>`_:
  real calculators over USB.
- The `CE C/C++ toolchain <https://github.com/CE-Programming/toolchain>`_ by the CE Programming team,
  with `convbin <https://github.com/mateoconlechuga/convbin>`_ and
  `spasm-ng <https://github.com/alberthdev/spasm-ng>`_.
- `Monaco Editor <https://github.com/microsoft/monaco-editor>`_ by Microsoft and
  `xterm.js <https://github.com/xtermjs/xterm.js>`_: the editor and the terminal.
- `Tauri <https://tauri.app/>`_: the desktop app.

Also
----

- The serial link follows the `TI Link Protocol Guide <https://merthsoft.com/linkguide/>`_.
- TIde works with `Ndless <https://github.com/ndless-nspire/Ndless>`_,
  `Luna <https://github.com/ndless-nspire/Luna>`_ and `py2ez80 <https://github.com/Voblit/py2ez80>`_,
  which you install yourself.
