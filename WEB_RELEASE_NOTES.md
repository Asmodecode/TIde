## TIde 1.6.2-web

A patch for the web version only, at https://xsamuraicoder.github.io/TIde/. The desktop app stays at 1.6.0 and doesn't update for this.

- **Opening folders:** Open folder now uses your browser's own system folder picker in every browser. In Chrome and Edge, TIde opens the folder itself and saves into it. Firefox and Safari can't save into folders on your computer, so TIde copies the folder you pick into a project kept in the browser, and says so.
- **Favicon:** the web version's tab now shows TIde's icon.
- Everything in 1.6.1-web and 1.6.0 is here too.
